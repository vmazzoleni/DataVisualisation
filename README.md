# DataVisualisation

An interaction design prototype exploring Swiss glaciers through geography, scientific visualization and time.

1. Current prototype
   Two overlapping views, animated focus switching, Aletsch selection, limited search, dataset filter and vertical timeline. Geographical shapes are illustrative; see the real historical data excerpt below. No real scientific reconstruction yet.

To display extensions, go to View → Show → File name extensions.

2. What each file controls
   File Purpose
   index.html Overall webpage structure
   css/style.css Layout, proportions, responsiveness and animations
   css/variables.css Colours and typography
   js/state.js Currently selected year, location and view
   js/geography.js Maps and glacier photographs
   js/visualization.js Scientific graphics and future 3D models
   js/timeline.js Years and data availability
   js/search.js Search functionality
   js/main.js Connects all the components
   data/glaciers.json Glacier measurements
